# Sub-Agent Practice Sandbox

This repository is a sandbox for practicing and demonstrating Claude Code's
**sub-agent** feature — the `Agent` tool that lets a main Claude Code session
dispatch independent, parallel agents to handle self-contained chunks of work.

## What is a sub-agent?

A sub-agent is a separate agent instance, spawned via the `Agent` tool, that
runs a focused task on its own: research, file edits, code generation, and so
on. It works independently of the main conversation and reports back a result
when finished. Because it does its work in its own context, the main
session's context window stays clean — no need to fill it with every
intermediate search result or file read. Multiple sub-agents can also run at
the same time, in parallel, to get several independent pieces of work done
at once.

## How this repo came to be

The initial contents of this repository — this `README.md`, a sample script,
and a short docs note — were themselves generated by **three sub-agents
running in parallel**, as a live, working demonstration of the feature
described above.
