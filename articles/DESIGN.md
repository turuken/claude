## ファイル命名規則

* `articles/thumb-<記事slug>.png` … サムネイル
* `articles/inline-<章の内容がわかる英名>.png` … 記事1の本文挿入画像
* `articles/inline-03art-NN-<slug>.png` … 記事3の本文挿入画像(NNは章番号)
* `articles/inline-04art-NN-<slug>.png` … 記事4の本文挿入画像(NNは章番号)
* `x-posts/x-post-<slug>.png` … note記事とは別に、X投稿専用の画像は`x-posts/`ディレクトリに保存する

## デザインの大原則

* **明るいデザインが基本**。暗い/怖い印象の配色は避ける(顕正会を離れた後の希望・自由を表現するテーマのため)
* **達成リストのアイコン列(💰🏠🚗✈️など)は避ける**。自慢っぽく見えて読者が不快に感じるとの指摘あり。実績に触れる場合は「現役時代→いま」のような概念的な対比で見せる
* **「罰」など不安を煽る漢字を大きく強調するのも避ける**(巨大な透かし文字などはNG、恐怖を煽る印象になった実例あり)
* サムネイルは日の出・光のモチーフ(🕊️鳩、太陽の光条など)を基本に、「恐怖から解放されて光が差し込む」というテーマを一貫させる
* 構成テンプレートは基本的に「タグバッジ(左上)＋見出し(太字)＋補足の一言・ビジュアル」のシンプルな型
* フォントは `IPAGothic` / `IPAPGothic`(環境にインストール済み)

## 画像の作り方(技術手順)

1. HTML+CSSでデザインを作成(1280px×360pxなど、目的のサイズぴったりで`html,body`を指定)
2. **必ず `headless_shell` バイナリでレンダリングする**。通常の `chrome` バイナリ(新ヘッドレスモード)は谷約88pxぶん高さがズレて画面下部が欠ける不具合があるため使わないこと

```bash
/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell \
  --disable-gpu --no-sandbox --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1280,360 --screenshot=out.png --virtual-time-budget=1000 \
  "file:///path/to/file.html"
```

* `--virtual-time-budget=1000` はJSで要素を生成する演出(太陽光条など)がある場合に必須
* dbus/sandbox関連のエラーログは無害なので無視してよい
* プロフィール画像を埋め込む場合は `プロフ画像.png`(リポジトリルート)をスクラッチパッドにコピーしてから相対パスで参照する
